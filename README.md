## 收录规范

- **只放自己整理的成果**：笔记、思维导图、索引、题目清单、可公开的链接。
- **不放受版权保护的原始材料**：出版社教材、机构讲义、课程视频、他人题库原文件，一律只记录来源链接，不做镜像分发。
- 每份资料标注 **来源、作者 / 讲师、版本或年份**；来源不清的先不入库。
- 优先保留可复现的文本（Markdown、提取后的 PDF 文本），大体积二进制文件不直接提交到仓库。
